1. Alfred Workflow 架构

数据流

两种输入类型对比

特性 Script Filter (type:5) Keyword (type:8) + Action (type:14)
动态输入 ✅ 支持 {query} ❌ 静态参数或复杂拼接
输出格式 XML (<items>) JSON (不可靠)
过滤能力 ✅ Alfred 内置搜索过滤 ❌ 无
推荐度 首选 仅用于简单固定参数场景

为什么不用 Keyword + Action？

旧版 FY Translator 使用 type:8 (Keyword) + type:14 (Action)，输出 JSON。在 Alfred 4 中：

  • JSON 输出被当作纯文本显示，而非结构化结果
  • 无法利用 Alfred 的搜索过滤功能
  • escaping 配置复杂，特殊字符容易出错

结论：始终使用 Script Filter (type:5)。

2. 核心概念

2.1 Keyword（关键词）

用户在 Alfred 中触发 workflow 的入口词。

最佳实践：

  • 简短、易记（1-3个字符）
  • 避免与系统命令冲突
  • withSpace: true → 用户必须输入空格后才触发（减少误触）

3.2 escaping 转义模式

escaping 值决定 Alfred 如何转义 {query} 中的特殊字符：

escaping 值 含义 适用场景
0 (None) 不转义 纯文本，无特殊字符
16 (AppleScript) AppleScript 转义 调用 AppleScript
32 (POSIX shell) POSIX shell 转义 bash/shell 命令
36 (反斜杠) \x → x Python 脚本（推荐）
64 (正则) Perl 兼容正则转义 正则表达式
128 (HTML) HTML 实体转义 Web API

FY Translator 使用 36（反斜杠），因为 Python 脚本中 {query} 可能包含空格、引号等，Alfred 会在前面加 \ 转义。

3.3 Alfred Workflow Editor（可视化编辑）

  1. 双击 .alfredworkflow 文件 → 打开 Alfred Workflow Editor
  2. 拖拽节点：左侧面板选择节点类型，拖到画布
  3. 编辑配置：点击节点 → 右侧面板修改参数
  4. 连接节点：拖拽节点之间的连线（Script Filter → Clipboard Output）
  5. 导出：File → Export 生成 .alfredworkflow

7.6 Alfred Workflow Editor 调试技巧

  1. 节点连线检查：确保 Script Filter → Clipboard Output 已连接
  2. uid 唯一性：每个节点 uid 必须唯一（重复会导致行为异常）
  3. escaping 模式：特殊字符问题 → 检查 escaping 值是否正确
  4. bundleid 一致性：确保 info.plist 中 bundleid 与代码中一致

8. 常见问题与陷阱

8.1 XML 输出问题

症状： Alfred 显示 “No Results” 或空白结果

排查步骤：

常见原因：

  • print() 输出到 stderr 而非 stdout
  • XML 根元素不是 <items>
  • Item 缺少 title 字段（Alfred 要求至少一个 item）

8.2 Python 3 兼容性问题

问题 原因 修复
AttributeError: module 'plistlib' has no attribute 'readPlist' Python 3.13 移除了 readPlist() 改用 plistlib.load(f) + 'rb' 模式
AttributeError: 'dict' object has no attribute 'iteritems' Python 3 没有 iteritems() 改用 items()
NameError: name 'unicode' is not defined Python 3 没有 unicode() 改用 str()
XML SubElement 报错 “argument 3 must be dict” 中文字符被错误解包为元组 检查 value 类型，确保是字符串而非 tuple

8.3 中文编码问题

症状： XML 输出中文字符乱码或报错

8.4 Script Filter 不触发

排查清单：

  1. ✅ keyword 拼写正确（区分大小写）
  2. ✅ withspace: true → 必须输入空格后触发
  3. ✅ Script Filter 节点类型是 type:5（不是 type:8）
  4. ✅ script 路径正确：/usr/bin/python3 translate.py "{query}"
  5. ✅ Python 脚本无语法错误（终端可运行）

8.5 Clipboard Output 不工作

症状： 点击结果后剪贴板没有内容

注意： clipboardtext 中的 {query} 引用的是 Script Filter item 的 arg 属性值。

8.6 特殊字符处理

问题： {query} 包含引号、空格等，导致 bash 解析错误

8.7 API 调用失败（422 / Connection Error）

症状： “翻译服务不可达” 或 API 返回错误

  4. 检查 bundleid 冲突：
